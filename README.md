# 💈 Graphical Saloon

**Graphical Saloon** is an interactive 2D graphics project developed using **C++ and OpenGL (GLUT)**. It simulates a virtual saloon where players can perform haircutting and shaving using keyboard and mouse controls.

## ✨ Features

- **Haircutting Simulation** — Use virtual scissors to cut a customer's hair.
- **Shaving Simulation** — Use a virtual razor to shave the customer's beard.
- **Interactive Controls** — Control tools using the mouse or keyboard.
- **Scoring System** — Earn or lose points based on your performance.
- **Customer Satisfaction** — View the customer's reaction based on the results.
- **2D Graphics** — Custom-drawn characters, tools, backgrounds, and interface elements using OpenGL.

## 🛠️ Technologies Used

- **Language:** C++
- **Graphics Library:** OpenGL
- **Windowing and Input:** GLUT (OpenGL Utility Toolkit)
- **Data Structures:** C++ STL Maps

## 🎮 Controls

| Key / Input | Action |
|---|---|
| `H` | Start haircutting mode |
| `S` | Start shaving mode |
| `W` | Move the tool upward |
| `A` | Move the tool left |
| `S` | Move the tool downward |
| `D` | Move the tool right |
| `G` | Perform a cutting or shaving action |
| `Q` | Finish the session |
| Mouse Movement | Move the active tool |
| Left Mouse Button | Perform a cutting or shaving action |


## 🖼️ Project Overview

The application features a custom-drawn customer, interactive grooming tools, and a scoring mechanism that evaluates the player's actions. It demonstrates fundamental computer graphics concepts through real-time interaction and 2D object rendering.

## 🎓 Academic Project

Developed as a project for Computer Graphics (CSE 322) to explore **2D rendering, geometric drawing algorithms, keyboard and mouse interaction, and graphical application development using OpenGL**.
